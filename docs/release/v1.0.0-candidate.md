## Lệnh xác nhận và tạo tag sau merge

Thực hiện ở checkout riêng sạch sau khi PR REL-01 đã merge; không reset workspace có thay đổi.

```powershell
git fetch origin --tags
git status --short
git log -1 --format='%H %s' origin/main
git ls-remote --tags origin refs/tags/v1.0.0
```

Đối chiếu SHA của PR REL-01 và xác nhận required checks pass. Chỉ khi remote không có tag,
đặt SHA đã xác nhận vào biến bên dưới; không dùng HEAD của nhánh cũ.

```powershell
$releaseCommit = '<MERGE_SHA_CUA_PR_REL_01>'
git tag -a v1.0.0 $releaseCommit -m 'UTEGear v1.0.0'
git push origin refs/tags/v1.0.0
git ls-remote --tags origin 'refs/tags/v1.0.0*'
```

Mẫu trên chưa được thực thi. GitHub Release nếu nhóm muốn công bố phải dùng tag này và release
notes đã review, không tự ghi đã deploy. Hướng dẫn chạy app/database nằm trong
[DOC-02](../setup/setup-and-demo.md).
